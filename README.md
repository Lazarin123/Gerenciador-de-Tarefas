### 🚀 Fluxo de Tarefas | Luxury Tech Manager

<p>O Fluxo de Tarefas é um gerenciador de alta performance desenvolvido para unir a precisão técnica da engenharia de software a uma estética refinada e minimalista. Projetado para ser intuitivo e eficiente, ele oferece uma visão 360° da sua produtividade através de listas dinâmicas, cronogramas visuais e análise de dados.</p>

---

### 💎 Diferenciais do Projeto

<p><strong>Estética Luxury Tech:</strong> Interface sofisticada com paleta de cores em cinza metal e azul marinho, utilizando efeitos de Glassmorphism e degradês modernos.</p>
<p><strong>Gestão Multidimensional:</strong> Navegação fluida entre Lista de Tarefas, Calendário Interativo e Dashboard de Estatísticas.</p>
<p><strong>Destaque Inteligente:</strong> O calendário identifica automaticamente o dia atual e diferencia tarefas concluídas de pendentes através de cores estratégicas.</p>

---

### 🛠️ Tecnologias Utilizadas

<p>Para garantir agilidade nas entregas e um código limpo, o projeto foi construído com:</p>

- HTML5 & CSS3: Estrutura semântica com layout baseado em CSS Grid e Flexbox.
- JavaScript (Vanilla): Lógica pura para manipulação do DOM e gerenciamento de estado.
- Chart.js: Biblioteca para visualização de dados de progresso em tempo real.
- FullCalendar: API de calendário profissional para controle de prazos e eventos.
- LocalStorage: Persistência de dados local para que suas informações nunca se percam.

--- 

### ⚙️ Funcionalidades Principais

- Dashboard de Tarefas: Adição detalhada com título, descrição, data de início e prazo final.
- Sistema de Filtros: Visualização rápida de tarefas "Todas", "Pendentes" ou "Concluídas".
- Agenda Visual: Calendário dinâmico com suporte para visualização mensal e semanal.
- Análise de Performance: Gráfico em rosca (Doughnut) que calcula automaticamente sua taxa de entrega.
- Modal Customizado: Interface de cadastro com fundo em degradê e desfoque de fundo (backdrop-filter).
